# Nginx 部署说明

线上是 **两层 Nginx**，不能合并成一个配置文件（两个进程、两种职责）。

| 放哪里 | 用哪个文件 | 做什么 |
|--------|------------|--------|
| **宝塔站点** | [`baota-site.conf`](baota-site.conf) | HTTPS、域名、整站反代到 `127.0.0.1:18081` |
| **Docker `gateway` 容器** | [`deploy/nginx/default.conf`](../../deploy/nginx/default.conf) | 前端静态、`/api`、`/uploads`、`.mjs` MIME（build 镜像时打进容器） |

## 部署顺序

1. 服务器：`docker compose up -d` 起服务，确认 `127.0.0.1:18081` 可访问（`GATEWAY_PORT` 可改映射端口）。
2. 宝塔：新建/编辑站点，把 **`baota-site.conf` 全文** 粘贴进站点配置（改 `server_name`、证书路径、日志路径）。
3. **不要**把 `deploy/nginx/default.conf` 贴到宝塔；**不要**把宝塔配置贴进容器。

## 自检

```bash
curl -sS http://127.0.0.1:18081/api/health/live
curl -sI "http://127.0.0.1:18081/assets/pdf.worker"*.js 2>/dev/null | grep -i content-type
# 期望：application/javascript（构建后 worker 为 .js；旧包可能仍为 .mjs，容器内已对 .mjs 单独设类型）
```

改容器内路由或静态策略：编辑 `deploy/nginx/default.conf` 后 `docker compose build gateway && docker compose up -d gateway`。

改 SSL/域名/外层反代：只改宝塔里的 `baota-site.conf` 内容，无需重建镜像。
